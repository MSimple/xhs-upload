# 功能清单与信息架构（新版）

## 1. 设计原则

1. **按工作流分组，而不是按技术模块分组**：创作 → 发布 → 数据 → 系统。
2. **工作台只回答三个问题**：今天要做什么、现在卡在哪、下一步点哪里。
3. **发布相关的高风险操作集中到一个“发布中心”**：队列、失败、连接状态和最近发布不再散落在作品库、创作营和设置里。
4. **长页面拆成标签页**：创作营、设置、数据看板不再是一条几千像素的长页面。
5. **移动端只保留 5 个主入口**：其余页面进入「更多」，避免 7 个 10px 图标挤在底部。

## 2. 菜单结构

### 桌面端侧边栏

| 分组 | 菜单 | 路由 | 职责 |
| --- | --- | --- | --- |
| 总览 | 工作台 | `/` | 今日待办、创作流水线、快捷上传/策划 |
| 内容创作 | 素材库 | `/library` | 导入、识别、筛选、批量、素材详情 |
| 内容创作 | 创作营 | `/campaign` | 常驻活动规则、生成排期、队列、积分、公告 |
| 内容创作 | 活动 | `/events` | 临时活动、截止时间、收集表、活动作品 |
| 内容创作 | 拍什么 | `/campaign/inspiration` | 素材缺口、拍摄清单、手机可执行的拍摄任务 |
| 发布运营 | 作品库 | `/posts` | 草稿/待发/已发布内容管理 |
| 发布运营 | 发布中心 | `/publish` | 今日队列、失败重试、账号状态、最近发布 |

### 移动端底部导航

主入口 4 个 + 「更多」：

1. 工作台
2. 素材
3. 创作（创作营）
4. 作品
5. 更多：活动、发布中心、发布日历、拍什么、数据看板、设置

## 3. 功能清单

### 3.1 工作台 `/`

**目标**：每天打开先知道「该做什么」，而不是先看一堆统计数字。

- 今日待办
  - 待识别素材 → 素材库
  - 待排期草稿 → 发布日历
  - 今日待发 → 发布中心
  - 发布失败 → 发布中心
- 创作流水线
  - 素材总数 → 已识别 → 已成稿 → 已发布
- 快捷创作
  - 上传照片/动图/视频
  - AI 智能策划
- 账号状态提示
  - 未登录小红书时提示去设置
  - 未配置 AI 时提示演示模式
- 最近作品
- 即将发布

### 3.2 素材库 `/library`

- 上传（拖拽/多选/自动识别）
- 搜索：文件名、摘要、场景、氛围、标签、选题、物体
- 筛选：全部/未使用/已排期/已使用/待识别/活动素材
- 类型筛选：图片/视频/动图
- 排序：最新上传/最早上传/封面潜力
- 批量：AI 识别、标记已用/未用、加入/移出活动、删除
- 素材详情：预览、AI 分析、标签、选题、重新识别、删除
- 演示分析识别与一键重识别
- 上传/缩略图/预览图链路

### 3.3 创作营 `/campaign`

**标签页**：概览 / 生成与排期 / 规则与体检 / 公告与收集表。

- 概览
  - 活动进度、当前批次、生成数量、剩余素材
  - 关键统计：待排期素材、已排期、本周已发布、本周积分
  - 接下来发布
  - 本次生成结果
- 生成与排期
  - 启用活动、自动补齐队列、生成后自动发布
  - 活动名称、车型词、创作者等级、每周篇数、发布时间、正文最少字数、储备周数、每批素材数、积分
  - 开始日期
  - 生成下一批 / 全部排期
- 规则与体检
  - 配图数、正文字数、车型话题、赛道话题、停用话题
  - 同日/同周超限
  - 车辆内容占比、AI/游戏/影视痕迹、流水账预警
  - 活动规则速览
- 公告与收集表
  - 群公告解析、飞书收集表链接
- 拍什么入口

### 3.4 临时活动 `/events`

- 活动列表：进行中 / 即将开始 / 已结束 / 全部
- 粘贴群公告自动识别：活动名、日期、话题、篇数、收集表、内部活动、二创要求
- 活动详情：规则、截止时间、建议发布时间、必带话题、配图/字数、收集表、小眼睛
- 活动作品：新建、AI 写活动稿、关联作品、规则体检
- 活动清单：已提交收集表、已登记小眼睛
- 活动发布：不计常驻活动周上限，周期内篇数独立控制；默认建议时间 21:30，可在活动里修改

### 3.5 拍什么 `/campaign/inspiration`

- 素材缺口统计
- 一组图的拍摄顺序
- 生成拍摄任务：分类、城市、重点、数量
- 任务卡片：地点、拍什么、机位、光线、道具、文案切入、优先级
- 勾选已拍、删除、清空、复制清单

### 3.6 作品库 `/posts`

- 状态：全部/草稿/待发布/已发布
- 搜索：标题、正文、主题、标签、活动
- 排序：最近编辑/排期日期/最近创建
- 作品卡片：封面、标题、摘要、活动、标签、排期/发布时间
- 作品详情：编辑、AI 重写、封面、排序、自动发布、手动标记、导出、撤回、删除
- **发布中心入口**（不再把队列信息塞进作品卡片）

### 3.7 发布中心 `/publish`（新增）

- 运行状态
  - 小红书连接/登录中/未登录
  - 到点自动发布开关
  - 今日待发、本周待发、失败数量
- 今日队列
  - 按时间排序，今日/逾期作品
  - 封面、标题、时间、活动、配图数
  - 打开作品详情处理
- 发布失败
  - 错误摘要、尝试次数
  - 查看失败截图
  - 打开作品重试/人工核对
- 本周排期
  - 未来 7 天队列
- 最近发布
  - 已发布作品与小红书链接

### 3.8 发布日历 `/calendar`

- 月视图，周一开头
- 本月已发布/计划待发/待排期统计
- 日期格「+」从某天开始排期（移动端也可见）
- 待排期草稿：默认 9 条，可展开全部
- 本月作品移动端列表
- 发布中心入口

### 3.9 数据看板 `/insights`

**标签页**：概览 / 笔记 / 粉丝。

- 概览：粉丝、关注、获赞与收藏、笔记总数、近 7/30 天流量/互动/粉丝与主页、账号诊断
- 笔记：最近笔记表、曝光/观看/点击/互动/涨粉等
- 粉丝：总粉丝、新增、流失、性别、兴趣、来源/活跃说明
- 同步数据、同步警告、上次同步时间

### 3.10 设置 `/settings`

**标签页**：账号与发布 / AI 模型 / 内容人设 / 环境与数据。

- 账号与发布：小红书登录/检测/退出、到点自动发布、隐藏浏览器窗口、访问令牌退出
- AI 模型：预设、Base URL、API Key、视觉/文本模型、启用 AI、测试连接（含视觉）
- 内容人设：人设、语言风格、签名、默认发布时间、每天发布篇数
- 环境与数据：Node/ffmpeg/浏览器状态、数据库/上传/截图占用、本地数据说明、备份提示

## 4. 路由与页面状态

| 路由 | 主要数据 | 主要动作 |
| --- | --- | --- |
| `/` | `/api/stats`、`/api/settings`、`/api/xhs/status` | 上传、AI 策划、跳转待办 |
| `/library` | `/api/images`、`/api/settings` | 上传、识别、筛选、批量、详情 |
| `/campaign` | `/api/campaign`、`/api/campaign/progress` | 生成、全部排期、保存设置 |
| `/events` | `/api/events` | 临时活动列表、粘贴公告创建 |
| `/events/[id]` | `/api/events/[id]` | 规则、活动作品、收集表/小眼睛、AI 写稿 |
| `/campaign/inspiration` | `/api/campaign/inspiration` | 生成/勾选/删除/复制 |
| `/posts` | `/api/posts` | 搜索、编辑、发布、导出 |
| `/publish` | `/api/posts`、`/api/xhs/status`、`/api/settings` | 处理队列、失败、打开作品 |
| `/calendar` | `/api/calendar`、`/api/posts` | 按月浏览、从日期排期 |
| `/insights` | `/api/platform`、`/api/xhs/status` | 同步、切换范围/标签 |
| `/settings` | `/api/settings`、`/api/xhs/status`、`/api/health` | 登录、配置、测试、查看环境 |

## 5. 与旧结构的变化

- 原「创作营」里的“接下来发布”改为只读队列预览，实际发布处理统一去「发布中心」；创作营只保留生成、规则、公告和积分。
- 原「设置」里的发布状态、自动发布开关、AI、人设、环境拆成四个标签页。
- 原「数据」的一页长内容拆成概览/笔记/粉丝。
- 底部导航从 7 个入口改为 4 个主入口 + 更多。
- 工作台的统计卡改为行动导向的今日待办 + 创作流水线。
- 新增 `/publish` 发布中心，承担“发布时”的操作，不再和“写内容”混在一起。
- 新增 `/events` 临时活动：群公告自动识别、独立话题/截止/篇数/收集表、活动稿生成和参与清单。

## 6. 暂不纳入本期

- 多账号切换
- 发布历史完整日志（目前保留最近发布与失败截图）
- 日历拖拽改期
- 素材软删除/回收站
- 云同步/多设备
