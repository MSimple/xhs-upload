# 薯光工坊 · 小红书灵感工作台

把相册里的照片整理成小红书笔记：AI 识图、按主题分组、写标题/正文/标签、排期、自动发布，并提供创作营活动规则校验、拍摄清单和创作中心数据看板。

临时活动（Power Day、发布会等）可以粘贴群公告自动识别日期、话题、篇数和收集表，独立截止时间，不占常驻活动周上限。

完整功能与菜单说明见 [docs/FEATURES.md](docs/FEATURES.md)。

## 环境要求

- **Node.js >= 22.5**（推荐 22 LTS 或 24）。项目使用 Node 内置的 `node:sqlite`。
- **Chrome 或 Edge**（自动发布和创作中心同步依赖本机浏览器，不需要单独下载 Playwright 浏览器）。
- **ffmpeg**（视频封面、动图转视频、GIF/HEIC 等格式的预览兜底）。没有 ffmpeg 时，视频/动图相关功能会不可用或缺少预览。
- Windows / macOS / Linux 均可。

## 启动

```bash
npm install
npm run dev
```

生产模式：

```bash
npm run build
npm start
```

默认只监听 `127.0.0.1:3000`。首次使用需要：

1. 打开设置页，配置 AI 模型服务（Base URL、API Key、视觉模型、文本模型）。
2. 点「测试连接」，确认文本模型和视觉模型都可用。
3. 点「登录小红书」，在弹出的浏览器窗口里完成登录。
4. 上传素材，等待 AI 识别，再使用智能策划或创作营排期。

## 手机 / 局域网访问（重要）

服务默认只允许本机访问。需要手机访问时：

```bash
# .env.local 或系统环境变量
XHS_ACCESS_TOKEN=换成一段足够长的随机字符串

npm run build
npm run start:lan
```

然后访问 `http://<电脑局域网 IP>:3000`，在登录页输入同一个令牌。

不设置 `XHS_ACCESS_TOKEN` 时，非本机请求会被拒绝。**不要把没有令牌的服务暴露到公网。** 这个应用保存着小红书登录状态和自动发布权限，等同于账号操作权限。局域网访问建议再套一层 HTTPS 或 VPN，避免令牌和图片在明文 HTTP 中传输。

生产入口是 `server.mjs`（`npm start` / `npm run start:lan`），它负责访问令牌、Host/Origin 校验和安全响应头；不要再用 `next start` 启动，否则会绕过这些保护。开发模式 `npm run dev` 也走同一个入口。

## 环境变量

| 变量 | 说明 |
| --- | --- |
| `XHS_ACCESS_TOKEN` | 可选。设置后启用访问令牌登录；远程访问必须设置。修改后需要重启/重新构建。 |
| `XHS_DATA_DIR` | 可选。数据目录，默认 `./data`。 |
| `XHS_BROWSER_PATH` | 可选。Chrome/Edge 可执行文件路径。 |
| `FFMPEG_PATH` | 可选。ffmpeg 可执行文件路径。 |

## 数据与备份

- `data/studio.db`：作品、素材、排期、设置、活动信息。
- `data/uploads/`：原图、预览图、缩略图。
- `data/xhs-profile/`：小红书登录 Cookie，**只保存在本机，不要提交到仓库**。
- `data/publish-shots/`：自动发布失败时的截图。

备份时复制整个 `data/` 目录即可。恢复时先停止服务，再覆盖回 `data/`。

## 自动发布说明

- 自动发布依赖本机浏览器和服务进程持续运行。
- 发布前会校验标题 20 字、正文加标签 1000 字、标签 10 个、配图数量、活动话题和活动日/周上限。
- 发布结果只有拿到明确的成功证据才会标记为已发布；登录失效、安全验证、未知跳转都会保留为失败，避免“假成功”和重复发布。
- 自动重试最多 3 次，失败后可在作品详情查看失败截图。
- 小红书页面结构、风控策略和活动规则都可能变化；发布前请人工确认内容合规。自动发布本身也可能违反平台条款，请自行评估账号风险。

## 常用命令

```bash
npm run dev        # 本地开发，仅本机
npm run dev:lan    # 局域网开发（配合 XHS_ACCESS_TOKEN）

```

## 已知边界

- 单账号、单实例；不支持多账号同时登录。
- AI 识图和文案质量取决于所配置的模型；视觉模型必须支持图片输入。
- 创作中心页面改版时，同步可能需要更新选择器；数据页会显示同步警告而不是静默返回 0。
- 素材库目前一次性加载全部素材；大量素材时建议先按类型/活动筛选。
