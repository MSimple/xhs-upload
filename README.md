# 薯光工坊 · 小红书灵感工作台

把相册里的照片整理成小红书笔记：AI 识图、按主题分组、写标题/正文/标签、排期，并在手动发布后回填发布状态。

临时活动（Power Day、发布会等）可以粘贴群公告自动识别日期、话题、篇数和收集表，独立截止时间，不占常驻活动周上限。

## 环境要求

- **Node.js >= 22.5**（推荐 22 LTS 或 24）。项目使用 Node 内置的 `node:sqlite`。
- **ffmpeg**（视频封面、动图转视频、GIF/HEIC 等格式的预览兜底）。没有 ffmpeg 时，视频/动图相关功能会不可用或缺少预览。
- Windows / macOS / Linux 均可。

## 启动

```bash
npm install
npm run dev
```

生产模式：

```bash
npm run build
npm start
```

默认只监听 `127.0.0.1:3000`。首次使用：

1. 打开设置页，配置 AI 模型服务（Base URL、API Key、视觉模型、文本模型）。
2. 点「测试连接」，确认文本模型和视觉模型都可用。
3. 上传素材，等待 AI 识别，再使用智能策划或创作营排期。

## 发布方式

应用不再登录小红书，也不自动发布。发布流程是手动的：

1. 打开「发布中心」，点作品右侧的「开始发布」。
2. 在发布助手里点「一键准备」：文案复制、发布包下载、小红书发布页打开。
3. 在小红书发布后，回到发布助手粘贴笔记链接，点「我已发布，标记完成」。
4. 标记后作品会变为「已发布」，配图锁定并计入已发布数据；需要修改时先「撤回标记」。

## 手机 / 局域网访问（重要）

服务默认只允许本机访问。需要手机访问时：

```bash
# .env.local 或系统环境变量
XHS_ACCESS_TOKEN=换成一段足够长的随机字符串

npm run build
npm run start:lan
```

然后访问 `http://<电脑局域网 IP>:3000`，在登录页输入同一个令牌。

不设置 `XHS_ACCESS_TOKEN` 时，非本机请求会被拒绝。**不要把没有令牌的服务暴露到公网。** 局域网访问建议再套一层 HTTPS 或 VPN，避免令牌和图片在明文 HTTP 中传输。

生产入口是 `server.mjs`（`npm start` / `npm run start:lan`），它负责访问令牌、Host/Origin 校验和安全响应头；不要再用 `next start` 启动，否则会绕过这些保护。开发模式 `npm run dev` 也走同一个入口。

## 环境变量

| 变量 | 说明 |
| --- | --- |
| `XHS_ACCESS_TOKEN` | 可选。设置后启用访问令牌登录；远程访问必须设置。修改后需要重启并重新构建。 |
| `XHS_DATA_DIR` | 可选。数据目录，默认 `./data`。 |
| `FFMPEG_PATH` | 可选。ffmpeg 可执行文件路径。 |

## 数据与备份

- `data/studio.db`：作品、素材、排期、设置、活动信息。
- `data/uploads/`：原图、预览图、缩略图。

备份时复制整个 `data/` 目录即可。恢复时先停止服务，再覆盖回 `data/`。

## 常用命令

```bash
npm run dev        # 本地开发，仅本机
npm run dev:lan    # 局域网开发（配合 XHS_ACCESS_TOKEN）
npm run build      # 生产构建
npm start          # 生产启动，仅本机
npm run start:lan  # 生产启动，监听所有网卡
npm run typecheck  # TypeScript 检查
npm run lint       # ESLint
npm test           # 纯逻辑测试（日期、内容限制）
```

## 已知边界

- 单账号、单实例；不包含小红书账号登录、数据同步或自动发布。
- AI 识图和文案质量取决于所配置的模型；视觉模型必须支持图片输入。
- 素材库目前一次性加载全部素材；大量素材时建议先按类型/活动筛选。
